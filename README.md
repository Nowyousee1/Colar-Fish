# 珊瑚鱼处理机
这是源于沈阳大学机械工程学院机械创新设计工作室的珊瑚鱼类一体式加工处理机项目的整体控制代码，基于STM32F407ZGT6实现
相当于可以理解为一个学生自主研发的工业自动化处理机械模型。本人从大一下开始学习江科大STM32到完成这项工程之间仅有不到2个月的时间，其中少不了自己对STM32的理解和Claude先生的帮助。有了Claude先生我才得以在那么短的时间一个人独自完成这个工程代码的编写
这里的所有代码是纯Claude完成，不掺一点人工成分哈。当然，工程里面的成分大家也可以直接用Claude进行读取，我这里也会进行简单的介绍
先后驱动日本电机（传送带）、威恒电机（丝杆）、水泵（冲洗装置）、气泵（切头刀）、电磁阀（控制切头刀），其中还有步进电机的东西，这个不在这个工程里，当时心急，用另一个STM32F103C8T6的板子实现了，然后建立了两个板子的USART通信完成的。当然这是完全可以并入这一个工程的，但是作为一个学习教育用的工程，目前来看没有必要，并且还同时用到了通信的内容，涉及面更广，就不加以修改了。全寄存器操作，没有HAL封装，这个其实可以选。
当然，值得提及的是这里为了实现威恒电机的正反转添加了L298N驱动模块。电机的驱动是通过板子上自带的继电器开关。
这个项目目前参加了大创项目立项（国家级）、三维大赛（）、智慧农业创赛（省三）
